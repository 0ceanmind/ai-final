# 🧠 Final Revision · AI Exam

A beautifully designed, single-file interactive study guide built for last-minute AI exam prep. Four chapters, 50+ flashcard definitions, and four randomized quizzes — all in one self-contained HTML page.

> *"Four chapters, fifty plus definitions, and four randomized quizzes. Built so you study the right things, not all the things."*

---

## ✨ Features

- **📖 Flashcard Definitions** — 50+ key AI terms organized as flip cards. Tap any card to reveal the definition and a memory hook. Filter by chapter or search by keyword.
- **📝 Randomized Quizzes** — One 5-question quiz per chapter, shuffled every time. Instant feedback with explanations for each answer.
- **🌗 Dark / Light Theme** — Toggleable at any time with smooth transitions.
- **🎨 Animated Background** — A live particle-network canvas that runs behind the page.
- **⚡ Interactive Demos** — Includes a live fuzzy logic temperature slider and an Ant Colony Optimization (ACO) swarm visualization.
- **📱 Fully Responsive** — Works on desktop and mobile.
- **🔋 Zero Dependencies** — Pure HTML, CSS, and vanilla JavaScript. No frameworks, no build step, no internet required after the font load.

## 📚 Chapters Covered

| # | Chapter | Topics |
|---|---------|--------|
| 1 | **Foundations of Artificial Intelligence** | History, subfields (ML, NLP, Robotics, Expert Systems), search algorithms (BFS, DFS, A*), Turing Test, AI timeline |
| 2 | **Neural Networks** | Perceptrons, activation functions, backpropagation, CNNs, RNNs, deep learning, training concepts |
| 3 | **Fuzzy Logic** | Crisp vs. fuzzy sets, membership functions, fuzzification, inference, defuzzification methods (CoG, MoM, CoS) |
| 4 | **Optimization** | Genetic Algorithms (GA), Ant Colony Optimization (ACO), selection/crossover/mutation, swarm intelligence |
